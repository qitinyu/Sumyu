### 镜像加速

1. 找到并复制想要克隆的仓库链接：
![2](https://i.postimg.cc/HL0TsD6j/image-1.png)
2. [访问镜像网站](https://gh-proxy.com/)，粘贴你的链接并一键转换：
![1](https://i.postimg.cc/s2P3DdTx/image.png)

>[!note]
>`原始链接`为文件下载转换链接，`Git Clone`链接则为 Git本地克隆链接。
3. 克隆镜像仓库,转换链接后复制任意一条：
![3](https://i.postimg.cc/yNh7Y4LD/image-2.png)
4. <kbd>win+r</kbd> 输入`cmd`，输入:
```cmd
cd /d D:\xx #切换到你的本地项目路径
git clone https://gh-proxy.org/https://github.com/xxxx/yxxxxz.git #进行镜像克隆
```
5. 等待克隆完成，克隆完成即可:
