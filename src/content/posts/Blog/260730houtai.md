# Sumyu 后台管理系统说明

### 系统组成

> 本后台用于在本地编辑 Sumyu 博客的内容与配置，并同步到正式仓库。

| 组件 | 作用 | 端口 |
|------|------|------|
| Astro 开发服务器 | 提供 `http://localhost:4321/admin/` 后台页面 | 4321 |
| decap-server | 本地文件存储后端，负责读写 `src/content/` 和配置文件 | 8081 |
| sync-server | 同步服务，把后台修改的内容复制到 `D:\YQ\Sumyu` | 8082 |
| 自定义 Admin 页面 | `src/pages/admin.astro`，提供文件夹树、编辑器、保存和同步按钮 | — |


> 启动命令：

```bash
pnpm cms:dev
```

该命令会同时启动上述三个服务。

---

### 可编辑内容

后台左侧分为三大区域：

1. 博文

- 对应文件夹：`src/content/posts/`
- 按子目录自动分组（如 `Blog`、`Github`、`Les` 等）
- 支持新建 `.md` 文件
- 右侧提供 frontmatter 表单：标题、日期、描述、作者、标签、置顶、加密、密码

2. 日记

- 对应文件夹：`src/content/diary/`
- 操作方式与博文相同

3. 站点配置

- 对应文件：`src/data/*.json`
- 可直接编辑以下配置：
  - 站点基础配置（`site.config.json`）
  - 顶部导航（`nav.config.json`）
  - 主题与设置面板（`theme.config.json`）
  - 社交链接（`social.config.json`）
  - 功能开关（`feature.config.json`）
  - 页脚配置（`footer.config.json`）
  - 友情链接（`links.config.json`）
  - 版本号（`package.json`）

> 配置文件目前为纯文本 JSON 编辑，保存时请确保格式正确。

### 操作流程

1. 启动

```bash
pnpm cms:dev
```

2. 然后浏览器打开：

```
http://localhost:4321/admin/
```

3.  编辑与保存

1. 在左侧点击文件或配置项
2. 在右侧编辑器中修改内容
3. 点击右上角 **保存** 按钮
4. 保存成功后底部状态栏显示 "已保存"

4.  同步到正式仓库

1. 确认修改已保存
2. 点击右上角 **同步到正式仓库** 按钮
3. 等待状态栏显示 "已同步到正式仓库"

5. 同步目标为 `D:\YQ\Sumyu`，可通过 `scripts/sync-to-repo.mjs` 或 `pnpm sync:repo` 手动执行。

---

### 同步范围

点击同步后，以下文件/文件夹会从测试目录复制到 `D:\YQ\Sumyu`：

- `src/content/posts/`
- `src/content/diary/`
- `src/data/`
- `src/config.ts`
- `src/pages/admin.astro`
- `public/admin/config.yml`
- `scripts/sync-to-repo.mjs`
- `scripts/sync-server.mjs`
- `admin-guide.md`

---

### 注意事项

1. **同步是单向覆盖**：测试目录 → 正式仓库。正式仓库中对应文件会被覆盖。
2. 同步前请确认正式仓库里没有未同步的重要修改。
3. 配置文件为 JSON 格式，编辑时请勿删除逗号、引号或括号。
4. 新建文章时，文件名建议只包含英文、数字、连字符 `-` 和下划线 `_`。
5. 如果后台无法加载，请检查 `pnpm cms:dev` 是否正常运行，以及端口 `8081` 和 `8082` 是否被占用。

---

### 部署前操作

在 `D:\YQ\Sumyu` 中完成同步后，进入该目录执行：

```bash
pnpm install
pnpm build
git add .
git commit -m "更新博客内容与配置"
git push
```

如果仓库已配置 GitHub Actions / Vercel / Cloudflare Pages，push 后会自动构建并部署。
