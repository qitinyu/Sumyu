> 每日一言，遇见心动的句子。

沐言是一款用 HarmonyOS 原生技术栈写就的**一言 · 想法 · Markdown 笔记**应用。它把「读到一句话」到「写下自己的话」串成一条线：每天在沐言页遇见一句新句子，在轩窗里为某一天标一种心情，在友迹里把想法摊开来看，也可以随时切到墨语，安静地写一篇长文。

当前版本 **V1.3.7**，适配手机、平板与 2in1。

---

## 版块一览

- 底部四个页签栏： **沐言 / 轩窗 / 墨语 / 友迹**
- 右侧Minibar：**陋室**

### 沐言 · 今日一言

- **今日一言**：接入一言（Hitokoto）云端接口，每天取一句新话；断网或接口超时自动回落到内置语料，离线也能看
- **推荐偏好**：按情感取向选句——静谧、欢喜、怅然、豁达、思念、悲伤、忧郁、兴奋，每种心情对应一组专属语料
- **卡片操作**：换一句、收藏、分享（自带复制）、发表想法，长按卡片还能调出文本排版（靠左 / 居中 / 靠右）
- **往日一言**：横向卡片流回看这几天读过的句子
- **搜索一言**：按内容、作者、出处检索全部本地语料，选中一句可以直接带去发表想法

*内置语料 700 余句，分诗词、人生、自然、情感、哲思、文学、现代、激励等多卷，全部取自公有领域或已授权的作品。*

### 轩窗 · 心情日历

把读到的句子，变成可回看的日子。

- 为某一天选一句语录、标一种心情，日历上留下对应颜色的记号
- 一天可以写下多条，日历以多个心情圆点像时钟指针一样依次排开
- 《 》调节年份，< > 调节月份，非当天的日期统一灰字，当天用主色高亮
- 点某个日期直接新建想法，点下方卡片进入已有想法的编辑页
- 每日待办-开发中，未落实

### 友迹 · 想法的动态（开发中，未落实）

自己的想法，也可以有卡片、有作者、有温度。

- 想法以空间式卡片呈现：头像、昵称、发布时间与机型
- 操作行支持点赞、评论、收藏、分享、更多（不看此想法 / 减少推荐 / 举报）
- 支持按时间最近或时间最久排序
- 图片按原图比例完整展示，多图同区域左右滑动，点开全屏并可左右翻看
- 与「陋室 · 记言」共用同一份数据，发布、编辑、删除后即时同步

### 墨语 · Markdown 写作

一条安静的写作支线，也是这套应用里最「工具」的部分。

**列表与整理**

- 卡片右滑分享，左滑移入回收站，长按调出置顶 / 重命名 / 复制 / 多选 / 导出 / 删除
- 支持多篇置顶、批量复制与批量删除
- 复制文章可按「末尾数字」或「末尾字母」自动递增命名，已占用序号自动跳过

**编辑与预览**

- 手机端「编辑 / 预览」双态切换，平板端直接左右分栏
- Markdown 渲染走 `@luvi/lv-markdown-in`，标题、列表、引用、代码块、表格、图片、链接均带应用主题样式
- 有序列表项之间空行不再打断编号；无序列表按层级换符号（一级 `•`、二级 `◦`、三级 `⋄`）
- 回车续写自动带缩进，空项再回车才退回上一级
- 预览里的链接用应用内底部弹窗打开，也可一键转交系统浏览器

**快捷操作栏**

- 按钮直接用语法符号本身：`#` `##` `-` `1.` `>` `B` `I` `S` `L` `` ` `` `</>` `[]` `![]` `▦` `` ``` `` `—`
- 最左侧固定一个撤销 `↶`，横向滑动时不动；700ms 内的连续改动合并成一步，最多回退 80 步
- 光标停在哪段格式里，对应按钮就点亮；取消格式后自动回落
- 可在设置里隐藏整条快捷栏，也可以长按图标拖动排序，松手即保存

**导出与分享**

- 导出：本地文件、Markdown、Word（.docx）
- 分享格式可选：纯文本 / Markdown / .txt / Word，按设置里选定的默认格式走
- 支持从本地导入 `.md` / `.markdown` / `.txt`
- 标题栏齿轮进入**墨语设置**：卡片样式（是否显示摘要）、复制自动命名规则、快捷栏开关与排序、默认分享格式

### 陋室 · 我的

- 华为账号授权登录，同步头像与昵称；支持两行 60 字的个性签名
- 收藏 / 点赞 / 评论 / 记言四宫格入口
- **沐言配置**：外观（跟随系统 / 浅色 / 深色）、底部栏自动隐藏、机型显示、卡片排版、WebDAV 备份与恢复
- **沐言信息**：应用内更新日志、关于沐言

## 数据与隐私

- 所有内容默认只存在本机应用沙箱：想法、文章、图片、收藏、偏好设置
- 云端一言只发送分类参数，不携带任何用户信息
- WebDAV 只与你填写的服务器通信，账号密码保存在本地 preferences
- 华为账号仅申请 `openid` 与 `profile` 两个 scope，用于取头像昵称，不上传内容
- 应用申请的权限只有网络相关两项：`ohos.permission.INTERNET`、`ohos.permission.GET_NETWORK_INFO`

## 技术栈

- **语言 / 框架**：ArkTS + ArkUI 声明式开发
- **SDK**：HarmonyOS，`compatibleSdkVersion 6.1.0(23)`，`targetSdkVersion 26.0.0`
- **设计系统**：`@kit.UIDesignKit` 的 HdsNavigation / HdsTabs / HdsNavDestination，沉浸光感材质
- **Markdown 渲染**：`@luvi/lv-markdown-in` 3.4.7
- **系统能力**：`@kit.ShareKit` 分享、`@kit.AccountKit` 华为账号、`@kit.ArkWeb` 内嵌网页、`@kit.CoreFileKit` 文件读写
- **持久化**：`@ohos.data.preferences` + AppStorage + 沙箱文件（`fileIo`）

MuYan/
├── AppScope/                     应用级配置（包名、版本、图标）
├── entry/
│   └── src/main/
│       ├── ets/
│       │   ├── entryability/     入口 Ability

│       │   ├── components/       想法卡片、引用卡片、图片网格等复用组件

│       │   ├── common/           偏好设置、主题、断点、素材、快捷栏工具表
│       │   └── utils/            WebDAV 同步、账号、分享、导出、图片存储

│       │   ├── base/             颜色、字符串、图标、布局
│       │   ├── dark/             深色模式色值

├── build-profile.json5           构建与签名配置
└── hvigor/ + hvigorfile.ts       构建脚本与 hvigor 配置
